# Kotlin Challenge. AMPPZ Finals 2026

We picked several simple problems from last year's ICPC competitions and implemented their solutions in Kotlin, but there’s a mistake in the code. Your goal is to find this mistake and correct it. You should only make a small correction rather than rewrite the entire code.

Find one mistake and correct it (each task has exactly one mistake) to get a souvenir at the booth! Correct all three mistakes and you get another souvenir 🙌

Task 1: [Fair Share](https://open.kattis.com/problems/fairshare)

Task 2: [Last Christmas](https://open.kattis.com/problems/lastchristmas)

Task 3: [Arcade Crane](https://open.kattis.com/problems/arcadecrane)
